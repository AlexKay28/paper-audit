# Aspect 18 — ICLR Compliance

**Dimension:** Does the paper satisfy ICLR submission rules — OpenReview,
anonymity, LLM disclosure, reproducibility statement, and ethics statement?

**Source basis:** `../rules/02-iclr-author-guide.md` (all sections);
`../rules/03-ml-reviewer-guidelines.md` §ICLR.

## How to answer

Answer each item **Yes** / **No** / **N/A**. **Pass if** states which answer
counts as a pass. See `README.md` for scoring.

## Items

### IC01. Are all authors' OpenReview profiles present and valid?
- **Pass if:** Yes
- **Rationale:** All authors are required to have OpenReview profiles.
- **Source:** `02` (OpenReview Profiles)

### IC02. Is the abstract genuine and informative (not placeholder/duplicate)?
- **Pass if:** Yes
- **Rationale:** Placeholder or duplicate abstracts are removed; the abstract
  drives reviewer bidding.
- **Source:** `02` (Submission Timeline)

### IC03. Are deadlines respected (abstract + full paper)?
- **Pass if:** Yes
- **Rationale:** Deadlines are final; no accommodations for missing either.
- **Source:** `02` (Submission Timeline)

### IC04. Are authors not added/removed after the abstract deadline?
- **Pass if:** Yes
- **Rationale:** Author set is frozen after the abstract deadline.
- **Source:** `02` (OpenReview Profiles)

### IC05. Is the submission anonymized (double-blind)?
- **Pass if:** Yes
- **Rationale:** ICLR uses double-blind review.
- **Source:** `02` (Reviewing Process)

### IC06. Is supplementary code self-contained and zipped into a single file (or anonymous URL)?
- **Pass if:** Yes
- **Rationale:** Supplementary code must be self-contained and anonymized.
- **Source:** `02` (Source Code Submission)

### IC07. Is all supplementary material anonymized?
- **Pass if:** Yes
- **Rationale:** Supplementary material is visible to reviewers and the public;
  anonymity is required.
- **Source:** `02` (Source Code Submission)

### IC08. Is supplementary text appended clearly (single file where possible)?
- **Pass if:** Yes
- **Rationale:** A single paper+supplementary file is preferred; supplementary
  must be marked clearly.
- **Source:** `02` (Supplementary text Submission)

### IC09. Are appendices placed after references (or as a separate supplementary file)?
- **Pass if:** Yes
- **Rationale:** Appendix placement is specified by the author guide.
- **Source:** `02` (Supplementary text Submission)

### IC10. Is the Code of Ethics acknowledged during submission?
- **Pass if:** Yes
- **Rationale:** Authors must read, adhere to, and explicitly acknowledge the
  Code of Ethics.
- **Source:** `02` (Code of Ethics & Ethics Statement)

### IC11. Is an Ethics Statement included where ethics concerns exist?
- **Pass if:** Yes
- **Rationale:** A separate ethics section is expected when concerns exist.
- **Source:** `02` (Ethics Statement)

### IC12. Is the Ethics Statement ≤ 1 page and placed before references?
- **Pass if:** Yes
- **Rationale:** The optional ethics statement is page-limit-exempt but capped
  at 1 page.
- **Source:** `02` (Ethics Statement)

### IC13. Is a Reproducibility Statement included?
- **Pass if:** Yes
- **Rationale:** ICLR strongly encourages a paragraph-long reproducibility
  statement.
- **Source:** `02` (Reproducibility Statement)

### IC14. Does the Reproducibility Statement reference (not duplicate) relevant sections/appendices?
- **Pass if:** Yes
- **Rationale:** The statement should point to details, not reproduce them.
- **Source:** `02` (Reproducibility Statement)

### IC15. Is the Reproducibility Statement ≤ 1 page and placed before references?
- **Pass if:** Yes
- **Rationale:** The optional reproducibility statement is page-limit-exempt
  but capped at 1 page.
- **Source:** `02` (Reproducibility Statement)

### IC16. Is LLM assistance in the core methodology disclosed (if non-standard)?
- **Pass if:** Yes
- **Rationale:** ICLR assesses LLM-use disclosure.
- **Source:** `03` §ICLR (Unique Considerations); `02`

### IC17. For new models/algorithms, is anonymous downloadable source code linked?
- **Pass if:** Yes
- **Rationale:** ICLR's recommended reproducibility approach for novel
  models/algorithms.
- **Source:** `02` (Reproducibility Statement)

### IC18. For theoretical results, are assumptions and appendix proofs complete?
- **Pass if:** Yes
- **Rationale:** ICLR's recommended reproducibility approach for theory.
- **Source:** `02` (Reproducibility Statement)

### IC19. For datasets, are data-processing steps fully described in supplementary?
- **Pass if:** Yes
- **Rationale:** ICLR's recommended reproducibility approach for datasets.
- **Source:** `02` (Reproducibility Statement)

### IC20. Does the paper avoid self-identifying arXiv references (anonymity)?
- **Pass if:** Yes
- **Rationale:** arXiv self-citation is allowed only in 3rd person, without
  explicit self-reference.
- **Source:** `02` (FAQ: arXiv self-citations)

### IC21. Is the main paper within the 10-page limit (camera-ready identical)?
- **Pass if:** Yes
- **Rationale:** Page limit is 10 pages; ethics/acknowledgements are exempt.
- **Source:** `02` (Camera-Ready Submissions)

### IC22. Are demo/video links anonymous (host not tracking visitors)?
- **Pass if:** Yes
- **Rationale:** Anonymous links are acceptable; the host must not track.
- **Source:** `02` (FAQ: Demos/videos)

### IC23. If reporting a challenge leaderboard ranking, is the challenge name cited?
- **Pass if:** Yes
- **Rationale:** Challenge rankings may be reported with the challenge name.
- **Source:** `02` (FAQ: Challenge leaderboards)

### IC24. Are ethics concerns raised via private message to the AC (not public)?
- **Pass if:** Yes
- **Rationale:** Violations during review go to the AC via OpenReview, not
  public channels.
- **Source:** `02` (Code of Ethics & Ethics Statement)

### IC25. Are Soundness / Presentation / Contribution each scored 1–4 (where self-assessed)?
- **Pass if:** Yes
- **Rationale:** ICLR's three sub-scores are the official review dimensions.
- **Source:** `03` §ICLR (Scoring)
